## Расхождения (сведены; часть закрыта 06.11)

1. Три разных обещания: «Пока это только визитка» / «Пока только визитка» / «Хватит читать». → В финале теперь «Хватит читать. Открывай.»
2. Два названия первого экрана. → Оставлено «Дневник употребления. Без лекций.»
3. «Два входа. Выбирай» без самих входов. → Добавлена секция «Где открыть» с тремя честными способами.
4. Медицинские оговорки разной силы. → Единая: «не вызывает скорую», «звони 112 сам».
5. «Пульс» есть только у одного сайта и не подтверждён в коде — не заявляем.
6. «4 важных правила» с одним раскрытым пунктом — у нас блок из четырёх карточек целиком.
7. PIN/экспорт как готовые. → Формулировка «если включишь».
8. «Без аккаунта» против Telegram-входа. → «Данные на телефоне, не в аккаунте»: аккаунт не хранит записи.

## Перенесённые формулировки

- «Через неделю уже не вспомнить — запись держит числа».
- «Пишется на устройство, не в аккаунт».
- «Скорую не вызывает — звони сам».
- «В чате ничего не появилось — и это нормально».
- «локальная защита четырьмя цифрами».
- «без рейтингов и стыда», «Один шаг, не клятва».

## Не переносить

- «Пульс».
- «4 важных правила» как нумерованный список с пропусками.
- Обещания, которых нет в сборке (расчёт концентрации «на борту» без партии).
