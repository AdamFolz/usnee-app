## Правила

1. Всё, что решено словами владельца, живёт здесь, а не в чате.
2. Секреты и ключи сюда не копируются.
3. Даты и источники обязательны: без них запись не считается контекстом.
4. Противоречия не сглаживаются — фиксируются как есть, с пометкой «решить».
