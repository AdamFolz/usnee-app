# Дизайн — направление B «Дневник»

> Утверждено владельцем 16.08.2026 в сессии `20260816_023538_885a0b`. Было потеряно: код остался на старом «premium dark fintech 2086» (фиолет, стекло, градиенты). Внедрено в приложение и лендинг 06.11.2026.

## Принцип

**Serif говорит, sans работает, mono считает.**

Теплота — от чернил, бумаги и шрифта, а не от свечения. Ни одного градиента, ни одного `backdrop-filter`. Это ещё и дешевле на слабых телефонах.

Один акцент. Вещества различаются маленькой цветной точкой, а не заливкой карточки.

## Типографика

- **Lora** (serif, кириллица) — заголовки, названия веществ, «голос дневника».
- **Onest** — интерфейс, кнопки, тексты.
- **JetBrains Mono** — дозы, время, счётчики, всё числовое.
- Капители 10–11px, трекинг `.14–.20em` — только служебные метки.

## Форма

Радиусы 6–16, пилюли только для сегментов периода. Тень вместо свечения. Зерно бумаги 5% (SVG-шум). Motion 240мс, без spring, `prefers-reduced-motion` уважается.

## Состояния (дословно)

| Состояние | Текст |
|---|---|
| Пусто | «Пока пусто» / «Первая запись — как первая строка. Дальше будет проще.» |
| Загрузка | скелет строк + «Чистится дневник…» |
| Ошибка | «Что-то пошло не так» / «Записи не пропали — они на устройстве. Прочитать не вышло.» / «Попробовать ещё раз» |
| Успех | «Записано» + тост, возврат на экран, отменить 5 секунд |
| Дубликат | красная пометка на полях «уже было в 22:50» + «записать всё равно» |

## Навигация

`Дневник · Журнал · Запись · Выписка · Профиль`. «Запись» — приподнятая квадратная кнопка акцентом. Активный таб — заливка `brand/12` и акцентный цвет.

## Экраны

- **Дневник**: дата капителью, приветствие серифом, последняя запись как заголовок статьи с пометкой на полях, интервал, две кнопки. Ниже — три быстрых действия и «на неделе».
- **Журнал**: метрики одной строкой, хитмап 12 недель, суммы доз, плотные строки с цветной полосой.
- **Выписка**: уровень + бар, «ритм недели», сегмент периода, плотная сводка.
- **Экстренно**: красный регистр, чтобы не путать с журналом.

## Честные риски

Lora в мелких подписях может «плыть» при тусклой подсветке — подписи держим Onest. Ламповость чуть медленнее инструментальной — компенсируется записью в один тап.
