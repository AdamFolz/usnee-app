# Архитектура

> Источник правды: `usnee/plan.md` + `docs/adr/`. Здесь — выжимка для навигации.

## Зафиксированные решения
- **Архитектура:** hybrid — offline-first клиент + обязательная серверная синхронизация
- **Платформа:** Telegram Mini App; бот обязателен
- **Дизайн:** premium dark fintech 2026
- **Публикация:** GitHub Pages `https://adamfolz.github.io/usnee-app/`

## Стек
- React 18 + TypeScript 5.2 + Vite 5.3 / 5.4
- TailwindCSS 3.4, recharts 2.12, lucide-react
- IndexedDB (idb 8) — local-first кэш + outbox
- vite-plugin-pwa — PWA, 8 precache (1183 KiB)
- @telegram-apps/sdk-react — Mini App SDK
- PostHog EU — analytics (autocapture off, allowlist 8 событий)
- Vitest + Testing Library — 227 тестов зелёных (26 сьютов)

## Структура репо (usnee/)
- `src/` — React + TS, Vite
  - `App.tsx` — роутинг
  - `components/` — AppShell, BottomNav, ConfettiBurst, Onboarding, PinLock, PanicButton
  - `components/home/` — HomeHeader, BatchHeroCard, SyncStatus, QuickActionGrid, WeeklySummaryCard
  - `components/record/` — HistoryDashboard, AdvancedRecordForm (мёртвый), AmountDisplay, ChoiceChip
  - `domain/` — stats.ts (канонические streak/dose/heatmap функции)
- `docs/adr/` — ADR-0001: hybrid sync, batch ledger, SOS boundary
- `docs/screen-state-matrix.md` — матрица состояний экранов (Loading/Ready/Empty/Offline/Failed)
- `.hermes/HANDOFF.md` — append-only межсессионный мост
- `BOARD.md` — канбан

## Ключевые узлы
- Quick Record — основной путь записи (1 тап, без review-шага)
- HistoryDashboard — хитмап (12 нед, 5 уровней), стрики, суммы доз
- AdvancedRecordForm — мёртвый код (1020 строк), не в роутах, оставить до Phase 5
- Конфетти/haptic — `ConfettiBurst.tsx`, `e338d47`
