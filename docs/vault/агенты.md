# Агенты

Рабочие заметки по Hermes-агентам и вайбкодингу.

## Контур
- Hermes desktop (этот чат) — оркестрация
- Claude Code / Codex / OpenCode — делегирование кода
- Buzz — командный чат агентов (ACP), M:\PROGRAMS\BUZZ

## Правила работы с vault
- Агенты читают/пишут md напрямую: `usnee/docs/vault/*.md`
- Ссылки wiki-стилем `[[заметка]]` — для навигации в Obsidian
- Перед стартом таска агенту: «прочитай [[архитектура]] и [[roadmap]]»

## Плагины Obsidian (установлены 03.09.2026)

- **hermes-agent** v0.10.1 — чат с Hermes из sidebar. API: `http://127.0.0.1:8642`, ключ в `data.json`. Команда: отправить заметку → стрим ответа в боковую панель

- **obsidian-git** v2.39.0 — git sync из Obsidian, auto-backup, diff (disablePush=true)

## Связка
```
Obsidian (vault) ↔ Hermes API Server (:8642) ↔ Hermes Agent ↔ Telegram
```
- API Server включён через `API_SERVER_KEY` в `.env`
- CORS: `http://127.0.0.1:8642`, `app://obsidian.md`
- Gateway автозапуск: `Startup/Hermes_Gateway.vbs` + watchdog
- Telegram: `require_mention=false`, чаты `-1004301333290` + `1019731503`

## Автономная работа (cron)
- **health-check** (`0092fa28dd0b`) — Python-скрипт `health-check.py`, каждые 15 мин. Проверяет: gateway, API :8642, Obsidian, диск M:, state.db размер. Silent on success (пустой stdout = нет алерта). Авто-рестарт gateway убран — cron блокирует lifecycle-команды (#30719).
- **autonomous-improve** (`0ea13b8fc6d9`) — агент: проверяет систему, улучшает vault, отчёт в ТГ, continuity mode.
- **tg-seksov-autodelete** (`c38c7b96260c`) — на паузе. Чистка логов бота.
