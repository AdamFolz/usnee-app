# Obsidian Vault (separated)

The full Obsidian vault has been moved out of the USNEE repo to keep the project clean.

**New location:** `M:\Obsidian\USNEE-vault`

## How to open
1. In Obsidian: File → Open vault → "Open folder as vault"
2. Navigate to `M:\Obsidian\USNEE-vault`
3. Open it.

## Sync
- Use Syncthing (recommended, as before).
- Re-add the folder `M:\Obsidian\USNEE-vault` in Syncthing on all devices.
- `.stignore` example:
  ```
  .obsidian/workspace.json
  .obsidian/cache
  *.tmp
  ```
